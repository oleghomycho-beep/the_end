> Вебзастосунок для моделювання спектрів екстинкції, поглинання та розсіювання металічних наночастинок методом дискретних диполів.

## ▶️ Як запустити проєкт "з нуля"

### 1. Встановлення інструментів

Для запуску проєкту потрібно встановити:

- Python 3.10 або новіший
- pip
- браузер Google Chrome, Microsoft Edge або Mozilla Firefox

### 2. Клонування або завантаження проєкту

Якщо проєкт розміщено в GitHub-репозиторії:

```bash
git clone https://github.com/oleghomycho-beep/the_end
cd optical
```

Якщо проєкт передано архівом, потрібно розпакувати його та перейти в папку проєкту:

```bash
cd path/to/project
```

### 3. Створення віртуального середовища

```bash
python -m venv venv
```

Активація середовища у Windows:

```bash
venv\Scripts\activate
```

Активація середовища у Linux / macOS:

```bash
source venv/bin/activate
```

### 4. Встановлення залежностей

```bash
pip install flask numpy scipy
```

Якщо у проєкті є файл `requirements.txt`, можна використати:

```bash
pip install -r requirements.txt
```

### 5. Запуск застосунку

```bash
python project.py
```

Після запуску сервер буде доступний за адресою:

```text
http://127.0.0.1:5000
```

## 🔌 API приклади

### Попередній перегляд дипольної моделі

**GET /api/preview**

Приклад запиту:

```text
/api/preview?material=Au&shape=sphere&radius_nm=50&num_dipoles=100&dipole_spacing_nm=5
```

**Response:**

```json
{
  "shape": "sphere",
  "material": "Au",
  "radius_nm": 50.0,
  "dipole_count": 100,
  "positions": [],
  "warnings": []
}
```

---

### Запуск моделювання

**POST /simulate**

Приклад параметрів форми:

```json
{
  "material": "Au",
  "material_model": "Drude model",
  "shape": "sphere",
  "radius_nm": 50,
  "dipole_spacing_nm": 5,
  "num_dipoles": 100,
  "wavelength_min_nm": 400,
  "wavelength_max_nm": 900,
  "wavelength_step_nm": 10,
  "environment": "Air",
  "polarization": "X"
}
```

Результатом є HTML-сторінка з графіком спектральних характеристик.

---

### Експорт результатів

**GET /download**

Приклад запиту:

```text
/download?material=Au&shape=sphere&radius_nm=50&wavelength_min_nm=400&wavelength_max_nm=900
```

Результатом є CSV-файл з такими колонками:

```text
wavelength_nm, frequency_hz, wavenumber_1_per_m, Q_ext, Q_sca, Q_abs, C_ext_m2, C_sca_m2, C_abs_m2
```

## 🖱️ Інструкція для користувача

1. Запустити сервер командою:

```bash
python project.py
```

2. Відкрити у браузері сторінку:

```text
http://127.0.0.1:5000
```

3. На головній сторінці вибрати параметри наночастинки:
   - матеріал;
   - форму;
   - радіус;
   - кількість диполів;
   - крок дипольної ґратки;
   - орієнтацію частинки.

4. Задати параметри моделювання:
   - діапазон довжин хвиль;
   - крок розрахунку;
   - середовище;
   - поляризацію;
   - інтенсивність;
   - амплітуду електричного поля;
   - температуру.

5. Переглянути 3D-модель дипольної ґратки.

6. Натиснути кнопку запуску моделювання.

7. На сторінці результатів переглянути:
   - графік екстинкції;
   - графік розсіювання;
   - графік поглинання;
   - максимальне значення екстинкції;
   - довжину хвилі резонансного максимуму;
   - таблицю результатів.

8. За потреби натиснути кнопку експорту та завантажити CSV-файл.

## 🧪 Проблеми і рішення

| Проблема | Можлива причина | Рішення |
|---------|-----------------|---------|
| Сторінка не відкривається | Flask-сервер не запущений | Запустити `python project.py` |
| Помилка `ModuleNotFoundError: flask` | Не встановлено Flask | Виконати `pip install flask` |
| Помилка `ModuleNotFoundError: numpy` | Не встановлено NumPy | Виконати `pip install numpy` |
| Помилка `ModuleNotFoundError: scipy` | Не встановлено SciPy | Виконати `pip install scipy` |
| Дуже довгий розрахунок | Задано забагато диполів або малий крок ґратки | Зменшити кількість диполів або збільшити крок |
| Некоректне 3D-прев’ю | Занадто мала кількість диполів | Збільшити `num_dipoles` або зменшити `dipole_spacing_nm` |
| CSV-файл не відкривається коректно | Неправильне кодування або роздільник | Відкрити файл через імпорт CSV у Excel / Google Sheets |
| Результати виглядають згладженими | Завеликий крок довжини хвилі | Зменшити `wavelength_step_nm` |
| З’являються попередження про обмеження | Параметри виходять за рекомендовані межі | Скоригувати радіус, крок ґратки або кількість диполів |
