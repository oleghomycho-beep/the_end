1. Координатна система

Усі відстані в нанометрах (нм). Центр (0, 0, 0) — центр наночастинки. Осі в куті сцени не обертаються з частинкою.

ЗеленийYВгору
СинійZНа глядача (вперед)

2. Шари 3D-сцени

2.1. Наночастинка

ЕлементВиглядФізичний зміст
Прозоре 3D-тіло + контур Сфера, еліпсоїд, куб або стрижень Реальна геометрія металевої частинки в середовищі
Колір поверхні Au — золотистий; Ag — сріблястий; Al — сіруватий Візуальний маркер матеріалу (не спектр поглинання)
Світіння (emissive) Сильніша реакція → яскравіше Пропорційно показнику відгуку |p|/(|α|E₀|)

2.2. Диполі — дискретизація DDA

ЕлементКолірФізичний зміст
Жовті кубики або точки Жовтий Вузли кубічної гратки: кожен вузол = один диполь DDA. Крок між вузлами — d (нм)
Розмір маркера — ≈ 22% від кроку d, щоб сітка виглядала щільною, не перекривала частинку

2.3. Дипольні моменти p⃗

ЕлементКолірФізичний зміст
Стрілки всередині частинки Червоний (відтінок за силою) Індукований дипольний момент p у вузлі; напрямок ≈ Re(p)
Довжина стрілки — Пропорційна |p|; порівняння між матеріалами можливе
Анімація коливань — Лише демонстрація (синусоїда довжини), не часовий розвʼязок Максвелла

2.4. Падаюче світло

ЕлементКолірФізичний зміст
Стрілка з центру Жовтий Напрям поляризації плоскої хвилі E₀ (X, Y або Z)
Стрілки вздовж променя Зелений Вектор поширення k⃗ (напрям енергії хвилі)
Синусоїдальна лінія Зелена Схематична плоска хвиля; число періодів ∝ 1/λ для 3D
Жовта сфера + стрілка Жовтий Умовне джерело світла з боку −k⃗
Einc(r) = E₀ · exp(i k·r),   k = 2π/λ

2.5. Near-field — |E|²

Увімкнення: чекбокс «Near-field |E|²» або режим «Near-field».

Колір точкиІнтенсивність поля
Синій / бірюзаСлабке локальне поле
Жовтий / помаранчевийСереднє поле
ЧервонийHot spot — підсилене поле біля поверхні

На оболонках і зрізах навколо частинки рахується |Einc + Escat|², де Escat — суперпозиція від усіх диполів. Контраст кольорів посилений (percentile + гамма).

3. Режими перегляду

РежимЩо відображається
Повний DDAЧастинка + диполі + p⃗ + хвиля + (опційно) near-field + середовище
ЧастинкаЛише геометрія та оболонка середовища
Диполі (voxel)Прозора частинка + жовта гратка
Моменти p⃗Частинка + червоні стрілки
Near-fieldЧастинка + кольорові точки |E|² + хвиля

Чекбокси «Гратка диполів», «Падаюча хвиля», «Near-field» керують шарами в режимі «Повний DDA».

5. Ланцюжок розрахунку (бекенд)

КрокФормула / модель
1. Довжина хвиліλ → ω = 2πc/λ
2. Матеріалε(ω): Drude, Drude-Lorentz або експериментальні Re/Im(ε)
3. Поляризовністьα = αCM / (1 − (4π/3) αCM Gii), Gii ≈ ik³/(6π)
4. Падаюче полеEinc,i = E₀ exp(i k·ri)
5. DDAΣj Aij pj = Einc,i
6. Near-field|E|² у зонах навколо частинки
β = (ε − εm) / (ε + 2εm),   αCM = Vcell · β

9. Обмеження моделі превʼю

Скалярна DDAОдна компонента поля; поляризація через E₀
